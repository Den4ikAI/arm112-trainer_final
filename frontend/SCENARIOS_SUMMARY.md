# Основные сценарии тренажёра

Выжимка из `SCENARIOS.md` (что снято с демок) плюс то, что из этого
превращено в рабочие экраны.

## Сценарий 1. Практика «карточка» — оператор 112

1. Вход (логин, пароль, номер АРМ).
2. Журнал происшествий → преподаватель или курсант запускает учебный вызов.
3. Открывается карточка, **стартует таймер**. Заявитель произносит легенду.
4. Курсант ведёт разговор: задаёт вопросы из банка, заявитель отвечает
   и только тогда раскрывает скрытые факты (город, этажность, газификация).
5. Курсант заполняет телефоны, ФИО и статус заявителя, адрес,
   описание, выбирает тип происшествия и признаки в опросной карте.
6. Список служб **пересчитывается сам** после каждого признака.
7. «Сохранить» → останавливается таймер → разбор.

Проверяется: полнота карточки, соответствие эталону, время против норматива,
и главное — **что курсант выяснил, а что домыслил**.

## Сценарий 2. Практика «действия с карточкой» — диспетчер ДДС

1. Вход, журнал, открытие поступившей карточки.
2. Карточка только для чтения: адрес, лента сообщений, признаки, класс.
3. Внизу плашки служб. У своей службы доступен карандаш.
4. Курсант проставляет статус: сначала доступны только **«Принята» /
   «Не принята»**, дальше цепочка раскрывается последовательно.
5. Для «Не принята» и «Отказа от выполнения работ» система **не сохранит
   статус без комментария** — это прямое требование памятки ДДС.
6. История статусов раскрывается синей панелью над плашкой.

Проверяется: своевременность (норматив 30 секунд), корректность статуса,
полнота комментария.

## Сценарий 3. Разбор

Три раздела:

* **Угадал, а не выяснил** — значение верное, но в стенограмме его нет.
* **Замечания** — не заполнено / ошибка / лишняя служба, каждое
  с последствием, а не с баллом: «служба не оповещена — фактически не выехала».
* **Заполнено верно** и полная стенограмма разговора.

## Что ещё предстоит

* Роли преподавателя и администратора (сейчас реализована роль обучающегося).
* Голос вместо текста: ASR на вход, банк TTS-реплик на выход.
* Мультиплеер: карточка летит от курсанта-оператора курсанту-диспетчеру.
* Импорт новой версии классификатора и переаттестация по дельте.

# Экранные сценарии, снятые со скриншотов боевой системы

Источник: `refs/СКРИНШОТ КАРТОЧКИ 112ГСИ.docx` (9 шт.), `refs/СКРИНШОТ ДДСГСИ.docx` (20 шт.),
`refs/Инструкция_по_заведению_карточки_2507ГСИ.docx`, `task/Работа с АРМ-112 для ДДС...pdf`.
Все скриншоты 1920×1080, браузер на 80–90% зума, внутренний стенд заказчика.

## S1. Вход в систему
Полноэкранная иллюстрация города, справа форма: «112 ВХОД В СИСТЕМУ», логин
(`umc_operdds1`), пароль, кнопка «ВОЙТИ», под ней телефон техподдержки и почта.
В инструкции: дополнительно поле «номер АРМ».

## S2. Журнал происшествий (главный экран)
- Строка «Поиск происшествий» + «расширенный по параметрам» + «сбросить».
- Справа тёмная панель: дата прописью, часы ЧЧ:ММ с мелкими секундами, строка
  пользователя (`, УМЦ O n`), иконки.
- «Список происшествий» — таблица: Связи / ЧС / Опер. / АРМ / Номер / Дата / Время /
  Тип происшествия / Постр. / Адрес / Статус службы.
- Под каждой строкой — раскрытая строка «Описание: <дата> <оператор> - <текст>».
- Пагинация: Страница, Записей на странице, «1-3 из 3».
- Пустое состояние: только шапка таблицы, «0 из 0».

## S3. Карточка 112 — пустая, приём вызова
Верх: кнопка сброса, «Отключение» (записи звонков / список SMS), три блока телефонов
(АОН / предоставленный / телефон на место), у двух — кнопка «АОН» для копирования.
Справа тёмный блок: «Происшествие <номер>», «Сохр. <дата> в <время>»,
«Опер. , АРМ 4, УМЦ O n» и **таймер ММ:СС** с подписями «минут / секунд».
Левая колонка: ФИО заявителя, «выберите статус», два пустых селекта, иконка перевода.
Блок «Адрес:» — единая строка + Страна / Субъект / Населённый пункт / Объект / Округ /
Район / Улица / Дом-Вл / Корпус / Стр-соор / Квартира-офис / Подъезд / Этаж / Код /
Описательный адрес, кнопка «очистить адрес».
Ниже «Описание со слов заявителя» со счётчиком `0 / 1999`.
Правая колонка: кнопки «Пострадавшие», «Нет на месте/Отказ от скорой»,
«Нет доступа/Заблокированные», справа «нет контакта» и «срыв звонка» (красные).
Блок «Введите тип происшествия» / «что случилось?» с плашками частых типов:
ДТП, Ошибочно набран номер, 104, Человек в опасности, Отмена вызова, Тестовый вызов,
Передача дежурства, Консультация, Вызов на иностранном языке, Справка-101.
Низ — оранжевая полоса «Службы:» с кнопкой «+» и справа «сохранить» + иконки
(связь, напоминание, важное, уведомления, сообщение об ошибке, закрыть).

## S4. Карточка 112 — выпадающий список типов
При вводе в строку — список: 101, 102, 103, 104, Аварии и происшествия в городском
хозяйстве, Аварии на гидротехнических сооружениях, Аварии на опасных и
производственных объектах, Благодарность службам, **БПЛА**, Взрыв, …
(БПЛА в проде подтверждает дифф классификаторов.)

## S5. Карточка 112 — опросная карта
Заголовок «добавить тип происшествия», плашка выбранного типа, тёмная шапка
опросной карты с крестиком. Строки «вопрос → плашки-ответы», выбранные **синие**.
Сняты три карты: «Происшествие 101», «Происшествие 104», «П: Взрыв».
Есть и текстовые поля (Этажность здания, Какие видят разрушения, Описание).

## S6. Карточка 112 — таймер и превышение норматива
00:07, 00:09, 00:32, 00:44 — тёмный фон. 01:03, 01:23, 02:07, 02:38 — **красный**.
Порог переключения — 60 секунд.

## S7. Карточка 112 — добавление служб
Модалка «Добавьте службы» с поиском, список: автоподобранные подсвечены синим,
остальные серые. Кнопка «Сохранить и закрыть». В нижней полосе службы появляются
плашками с крестиком: Служба 101, Служба 104, Служба 102, Деп. ЖКХ, ЦЭМП, ЦОДД,
Мос.Без., Мослифт.

## S8. Карточка 112 — карта
Отдельное окно «С112 - карта»: поля Широта / Долгота / ОК / «Указать на карте»,
справа выбор радиуса (50 м) и «Слой». Карта Яндекса с точкой происшествия.

## S9. Карточка ДДС — просмотр
Тот же каркас, но поля read-only и серые. Справа вместо таймера кнопки «просмотр»
и «дополнение». Строка «Пострадавшие: нет  Отказ от скорой: нет  Заблокированные: нет»,
кнопки «ЧС», «ЧП» (оранжевая), карандаш.
Блок признаков: «Происшествие 101» → перечисление через точку
«Дом . Открытое пламя / Дым (дом), Запах гари (дом) . Дом многоквартирный . квартира .
Есть угроза людям . Есть газификация .», строка «Класс.: пожар: квартира ;»,
строка «[ВИС] Класс.:».
Слева — адрес и лента сообщений «<дата> <время> <оператор> — <текст>».

## S10. Карточка ДДС — проставление статуса
Внизу плашки служб с подписью «11:14 Добавлена». На плашке своей службы —
стрелка (история) и карандаш (новый статус).
По карандашу открывается строка: **Статус** (выпадающий) / **Номер наряда** /
**Комментарий** / ✓ / ✗.

## S11. Карточка ДДС — последовательность статусов
Выпадающий список отдаёт только следующие допустимые: после «Принята» —
Прибытие, Отказ от выполнения работ, Работы завершены (и Начало реагирования).
Первичные — только «Принята» / «Не принята».

## S12. Карточка ДДС — история статусов
Синяя панель над плашкой службы, строки `оп. 0 › <дата> <время> <статус> › <комментарий>`:
```
11:14:04 Добавлена
11:19:24 Получена службой
11:23:21 Принята            › Отправлн сантехник для перекрытия воды
11:29:04 Начало реагирования › Сантехники приступили к работе по перекрытию воды в доме
11:32:13 Прибытие            › Дополнительно прибыли рабочие
11:33:40 Проведение работ    › Работы ведутся
```
Плашка службы в свёрнутом виде показывает последний статус: «11:33 Проведение …».

# Что из этого строим (учебная надстройка)

Это **тренажёр**, а не боевая система, поэтому поверх точной копии добавлены:
- **HUD обучающегося**: легенда вызова, банк вопросов заявителю, лента разговора.
- **Норматив** вместо просто таймера: порог задаётся преподавателем (дефолт 60 с
  для карточки, 30 с для подтверждения ДДС).
- **Разбор**: дифф «эталон ↔ введено», отдельно помеченные поля, которые курсант
  заполнил, **не выяснив** их у заявителя («угадал», а не «узнал»).

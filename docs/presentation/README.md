# Презентация к сдаче

`docs/презентация.pptx` (и `docs/презентация.pdf`) собирается скриптом
из шаблона организаторов ЛЦТ-2026:

```bash
pip install python-pptx
python docs/presentation/build_pptx.py "refs/материалы-задачи/Презентация/ЛЦТ2026 Шаблон презентации.pptx"
soffice --headless --convert-to pdf --outdir docs docs/презентация.pptx
```

Слайды 1–5 — обязательный блок шаблона (там это слайды 7–11): дизайн и
сетка не менялись, заменён только текст в существующих фигурах. Всё о
команде помечено `[ЗАПОЛНИТЬ: …]`, зависящее от ещё не слитой работы —
`[ПРОВЕРИТЬ]`. Остальные слайды — описательная часть на макетах шаблона.

Кадры в `screens/` сняты с тренажёра на отдельной чистой базе:

```bash
cd frontend/e2e
TEST_DATABASE_URL=postgres://arm112:arm112@localhost:5432/<чистая база> \
ML_PROVIDER=http ML_BASE_URL=http://127.0.0.1:8090 \
E2E_API_PORT=8161 E2E_WEB_PORT=5261 \
npx playwright test --config playwright.capture.config.ts presentation
```

Кадр анализа текста снят на настоящей модели (GigaChat 3.1); ответ модели
от прогона к прогону может отличаться.

`logo-dgochs.png` — логотип постановщика задачи из того же шаблона
(слайд 6, белая версия для тёмного фона).

# Презентация к сдаче

`docs/презентация.pptx` (и `docs/презентация.pdf`) собирается скриптом
из шаблона организаторов ЛЦТ-2026:

```bash
pip install python-pptx
python docs/presentation/build_pptx.py "refs/материалы-задачи/Презентация/ЛЦТ2026 Шаблон презентации.pptx"
soffice --headless --convert-to pdf --outdir docs docs/презентация.pptx
```

Текст выступления и ответы на вероятные вопросы экспертов —
`выступление.md`.

## Как устроена

**Слайды 1–5** — обязательный блок шаблона (там это слайды 7–11): дизайн
и сетка не менялись, заменён только текст в существующих фигурах. Всё о
команде помечено `[ЗАПОЛНИТЬ: …]`.

**Слайд 6 — карта соответствия.** Каждый вопрос, который задают критерии
экспертизы ТЗ и заказчик в чате, — и номер слайда с ответом.

**Слайды 7–24** — по одному критерию или вопросу на слайд, заголовок
называет критерий. Внизу каждого — строка «Требование: …»: раздел ТЗ,
номер сообщения в чате задачи, сессия вопросов и ответов. Цитаты
заказчика и организаторов — дословно, с номером сообщения.

## Метки

* `[ЗАПОЛНИТЬ: …]` — данные команды и ссылки;
* `[ЦИФРА: …]` — число, которого ещё нет в замерах (прогноз,
  рекомендации); выдумывать нельзя;
* `[СКРИН: …]` — место под снимок, которого ещё нет: скрипт рисует
  рамку-заглушку и сам подставит снимок, когда файл появится
  (`screens/audit/прогноз.png`, `screens/audit/рекомендации.png`);
* `[ПРОВЕРИТЬ]` — утверждение, которое надо сверить после слияния
  параллельной работы.

## Откуда кадры

* `screens/p01…p12` — сняты с тренажёра на отдельной чистой базе
  (`frontend/e2e/capture/presentation.spec.ts`);
* `screens/p14`, `p15`, `p16` — кадры демо-ролика (`docs/demo/`), без
  его титров;
* `screens/ref-ддс.png`, `ref-112.png` — кадры боевой системы из
  материалов задачи; адресная строка браузера (внутренний адрес стенда
  заказчика) и панель задач обрезаны;
* карточки 112 и ДДС с полосами служб — `frontend/screenshots/react/`.

`logo-dgochs.png` — логотип постановщика задачи из того же шаблона
(слайд 6, белая версия для тёмного фона).

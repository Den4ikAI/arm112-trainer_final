# Презентация к сдаче финала

`docs/презентация.pptx` (и `docs/презентация.pdf`) собирается скриптом
из шаблона организаторов ЛЦТ-2026:

```bash
pip install python-pptx
python docs/presentation/build_pptx.py "refs/материалы-задачи/Презентация/ЛЦТ2026 Шаблон презентации.pptx"
soffice --headless --convert-to pdf --outdir docs docs/презентация.pptx
```

Текст выступления отбора и ответы на вероятные вопросы экспертов —
`выступление.md`.

## Как устроена

**Слайды 1–5** — обязательный блок шаблона (там это слайды 7–11):
дизайн и сетка не менялись, заменён только текст в существующих фигурах.

**Слайды 6–17** — сюжет финала, по одному шагу на слайд:

| № | Слайд | Кадры |
|---|-------|-------|
| 6 | Зачем это нужно | — |
| 7 | Решение: замкнутый цикл обучения | схема пяти шагов |
| 8 | Рабочее место диспетчера ДДС | `final/06` — карточка с подсказками |
| 9 | Происшествие от ИИ | `final/12` — учебный материал |
| 10 | Бригада и IP-телефон | `final/03` — окно телефона |
| 11 | Оценка и разбор | `p04` — анализ текста с цитатами |
| 12 | Рекомендации и следующее задание | статистика демо-стенда |
| 13 | Преподаватель | `teacher/01б`, `final/11` — телефоны ДДС |
| 14 | Администратор и вход | `final/10` — экран входа |
| 15 | Закрытый контур и технологии | — |
| 16 | Что сделано после отбора | — |
| 17 | Как посмотреть | — |

Числа на слайдах — из README, документации `docs/1…4` и статистики
демонстрационного стенда (слайд 12, подписана: учебная группа из
10 симулированных курсантов).

## Откуда кадры

* `screens/final/01…06` — рабочее место ДДС с подсказками и телефоном,
  сняты с предпросмотра финальной сборки (1280×720);
* `screens/final/10…16` — экран входа, телефоны ДДС, учебный материал,
  аналитика, администрирование, занятия — оттуда же;
* `screens/p01…p16`, `screens/teacher/`, `screens/audit/` — кадры отбора
  (`frontend/e2e/capture/presentation.spec.ts`, демо-ролик, сравнения
  с образцами);
* `team-*.jpg` — фото команды.

`logo-dgochs.png` — логотип постановщика задачи из того же шаблона
(слайд 6, белая версия для тёмного фона).

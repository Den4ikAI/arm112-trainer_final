# Перед сдачей

Стоп-код — **29 сентября, 23:59 МСК**. Форма в личном кабинете закроется
сама. После этого нельзя ничего трогать — ни код, ни документы, ни стенд:
за это дисквалификация, таймштампы коммитов и файлов проверяют.

Порядок ниже рассчитан так, чтобы к вечеру 29-го оставалось только
нажать «сохранить» в форме.

## 28 сентября — всё собрать

- [ ] Все ветки слиты в `main`, серверные и браузерные проверки зелёные.
- [ ] Прототип развёрнут на сервере по `deploy/README.md`.
- [ ] Проверено **снаружи**, по той ссылке, что пойдёт в форму: вход
      под курсантом, преподавателем и администратором; учебный вызов от
      начала до разбора; карточка приходит в ДДС; занятие; аналитика.
- [ ] Сервер переживает перезагрузку: `sudo reboot`, через пару минут
      ссылка снова открывается без ручных действий.
- [ ] Документация пересобрана с актуальными числами:
      `python3 docs/build.py`, файлы `docs/документация.pdf` и `.docx`
      закоммичены.
- [ ] Презентация по шаблону (`refs/материалы-задачи/Презентация/`),
      обязательные слайды 7–11 в дизайне шаблона. Выгружена в PDF
      и лежит на облаке с доступом «все, у кого есть ссылка».

## 29 сентября, днём — открыть репозиторий

Публичность — только в самом конце, перед заполнением формы.

- [ ] **`transcript/dialog.md`** — выгрузка рабочего диалога. В ней
      команда SSH-туннеля, IP сервера и путь к ключу. Решить: вычистить
      эти места или убрать файл. Он есть и в истории git — удалить файл
      последним коммитом мало, нужна перезапись истории
      (`git filter-repo --path transcript/dialog.md --invert-paths`)
      или вычистка строк через `--replace-text`.
- [ ] **`frontend/screenshots/reference/`** — кадры боевой системы:
      внутренний адрес стенда и логин учётной записи. Материалы выданы
      всем участникам, но публикуются уже нами. Решить: оставить или
      убрать из истории тем же способом.
- [ ] Поиск секретов по всей истории, а не только по текущему дереву:
      `git log -p --all | grep -inE "password|secret|token|BEGIN .*KEY|id_rsa"`.
      `.env` в git не лежит — проверить: `git log --all -- backend/.env`
      должно быть пусто.
- [ ] После перезаписи истории — `git push --force` и проверка, что
      на GitHub нет старых веток со старой историей.
- [ ] GitHub → Settings → Change visibility → **Public**.
- [ ] Открыть репозиторий в приватном окне браузера: README читается,
      инструкция по запуску на месте.

## После 23:59 — ничего не трогать

- Никаких `git push` в этот репозиторий — ни в `main`, ни в другие ветки.
- Не править документацию и презентацию по ссылкам.
- **Не обновлять и не перезапускать стенд вручную.** Сервер
  перезапускается сам после сбоев (`restart: unless-stopped`) — этого
  достаточно.
- Доработка — только локально или в отдельном приватном репозитории,
  не связанном со сданной ссылкой. На оценку отборочного этапа она не
  влияет.
